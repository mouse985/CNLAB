# CNLab语法分析报告

## 问题代码

```matlab
x = [0:0.01:5]; 
y = exp(-1.5*x).*sin(10*x); 
subplot(1,2,1) 
plot(x,y), xlabel('x'),ylabel('exp(–1.5x)*sin(10x)'),axis([0 5 -1 1]) 
y = exp(-2*x).*sin(10*x); 
subplot(1,2,2) 
plot(x,y),xlabel('x'),ylabel('exp(–2x)*sin(10x)'),axis([0 5 -1 1])
```

## 语法问题分析

### ❌ 不支持的语法特性

#### 1. **逗号作为语句分隔符**

**MATLAB语法**:
```matlab
plot(x,y), xlabel('x'), ylabel('y'), axis([0 5 -1 1])
```

**CNLab当前行为**:
- CNLab **不支持**逗号作为语句分隔符
- 逗号仅用于：
  - 函数参数分隔: `func(a, b, c)`
  - 矩阵元素分隔: `[1, 2; 3, 4]`
  - 数组索引: `A(i, j)`

**解决方案**:
```matlab
# 方案1: 使用分号或换行分隔语句
plot(x, y)
xlabel('x')
ylabel('y')
axis([0, 5, -1, 1])

# 方案2: 使用分号
plot(x, y); xlabel('x'); ylabel('y'); axis([0, 5, -1, 1])
```

### ⚠️ 其他潜在问题

#### 2. **axis函数参数格式**

**MATLAB语法**:
```matlab
axis([0 5 -1 1])  # 空格分隔
```

**CNLab要求**:
```matlab
axis([0, 5, -1, 1])  # 逗号分隔
```

**说明**: CNLab的矩阵/数组元素必须使用逗号分隔，不支持纯空格分隔。

#### 3. **字符串引号**

**MATLAB语法**:
```matlab
xlabel('x')  # 单引号
```

**CNLab支持**:
```matlab
xlabel('x')  # ✅ 单引号支持
xlabel("x")  # ✅ 双引号也支持
```

**说明**: CNLab同时支持单引号和双引号字符串。

#### 4. **范围表达式在方括号内**

**MATLAB语法**:
```matlab
x = [0:0.01:5];
```

**CNLab支持**:
```matlab
x = [0:0.01:5];  # ✅ 支持
x = 0:0.01:5;    # ✅ 也支持（更简洁）
```

**说明**: CNLab支持范围表达式，方括号是可选的。


## 📋 CNLab语法差异总结

| 特性 | MATLAB | CNLab | 状态 |
|------|--------|-------|------|
| 语句分隔符 | `,` 或 `;` 或换行 | 仅 `;` 或换行 | ⚠️ 差异 |
| 矩阵元素分隔 | 空格或逗号 | 仅逗号 | ⚠️ 差异 |
| 字符串引号 | 单引号 `'` | 单引号或双引号 | ✅ 兼容 |
| 注释符号 | `%` | `#` | ⚠️ 差异 |
| 范围表达式 | `[start:step:end]` | `start:step:end` 或 `[start:step:end]` | ✅ 兼容 |
| 元素级运算 | `.*`, `./`, `.^` | `.*`, `./`, `.^` | ✅ 兼容 |
