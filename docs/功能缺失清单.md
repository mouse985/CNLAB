# CNLab 功能缺失清单

## 1. 核心解释器缺失 (10%)

### 1.1 数据类型缺失

| 缺失功能 | 说明 | MATLAB示例 |
|----------|------|------------|
| 复数类型 | 不支持复数运算 | `z = 3 + 4i` |
| 结构体 (struct) | 不支持结构化数据 | `s.name = 'Tom'` |
| 元胞数组 (cell) | 不支持cell数组 | `C = {1, 'a', [1 2]}` |
| 表格 (table) | 不支持表格数据 | `T = table(x, y)` |
| 分类数组 (categorical) | 不支持分类数据 | `c = categorical({'a', 'b'})` |
| 日期时间 (datetime) | 不支持日期时间 | `d = datetime('now')` |
| 持续时间 (duration) | 不支持时间间隔 | `t = hours(5)` |

### 1.2 控制流缺失

| 缺失功能 | 说明 | MATLAB示例 |
|----------|------|------------|
| switch-case | 多分支选择 | `switch x; case 1; ...; end` |
| try-catch | 异常处理 | `try; ...; catch; ...; end` |
| 匿名函数 | 内联函数定义 | `f = @(x) x^2` |
| 函数句柄 | 函数引用 | `h = @sin` |
| 可变参数 | varargin/varargout | `function y = f(varargin)` |
| 全局变量 | global关键字 | `global x` |
| 持久变量 | persistent关键字 | `persistent x` |

### 1.3 运算符缺失

| 缺失功能 | 说明 | MATLAB示例 |
|----------|------|------------|
| 三元运算符 | 条件表达式 | `y = x > 0 ? 1 : -1` (MATLAB不支持，但有类似功能) |
| 位运算 | 按位与或非 | `bitand, bitor, bitxor` |
| 短路逻辑 | 更智能的短路 | 已实现 && 和 \|\| |

### 1.4 其他缺失

| 缺失功能 | 说明 |
|----------|------|
| 类与面向对象 | 不支持classdef定义类 |
| 包/命名空间 | 不支持+package语法 |
| 属性验证 | 不支持arguments块 |
| 并行计算 | 不支持parfor/spmd |
| MEX接口 | 不支持C/C++扩展 |
| 调试功能 | 不支持断点、单步执行 |
| 性能分析 | 不支持profiler |

## 缺失汇总

| 类别 | 已完成功能数 | 缺失功能数 | 完成度 |
|------|-------------|-----------|--------|
| 核心解释器 | ~40 | ~15 | 73% |
| 数学运算 | ~50 | ~20 | 71% |
| 矩阵功能 | ~60 | ~15 | 80% |
| 字符串处理 | ~12 | ~25 | 32% |
| 文件I/O | ~20 | ~5 | 95% |
| 绘图功能 | ~19 | ~13 | 70% |

**关键缺失（建议优先实现）：**

1. **高优先级**：复数支持、switch-case、try-catch、sprintf
2. **中优先级**：图形保存功能（saveas, print）、图像显示（imshow）
3. **低优先级**：稀疏矩阵、3D数组、正则表达式、Excel支持、3D绘图
